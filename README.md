# Abacus Lisp

A small and purpose-built Lisp dialect focused on scientific problem solving.

Think of this Lisp dialect as a graphing calculator built on top of a custom
Lisp interpreter.

## Inspiration

I've always wanted to write my own Lisp and my own mathematical/scientific
software environment (such as MATLAB and Maple). This is my
[second attempt](https://github.com/nathanpc/bamboo-lisp) at building a Lisp
interpreter based on the amazing [Building LISP](https://lwh.jp/lisp/) tutorial
series.
